# 多币种账户与每日汇率

1.4.0 起，外币账户默认每天自动联网查询汇率。人民币 CNY 固定为 1。支持 USD、USDT、JPY、EUR、HKD、GBP、KRW、SGD、AUD、CAD、CHF、TRY。旧人民币账户与原币余额保持兼容。

## 更新节奏

- 应用启动后检查；应用或托盘后台运行时每天自动查询一次。完全退出或电脑关机期间不运行，下次启动补查。
- 账户表单和账本设置提供“刷新汇率”，自动模式显示报价日期、获取时间和来源。
- 失败保留最近成功数据，稍后重试。周末、节假日可能继续使用最近交易日的公开报价；获取时间与报价日期分别显示。
- 可将单个账户改为手动汇率，自动更新不会覆盖。没有可用报价时可切为手动填写后记账。

## 公开数据与联网范围

法币使用 [Frankfurter 的 ECB 数据](https://frankfurter.dev/)，每日参考报价并非银行实际结算价。接口请求以 CNY 为基准，换算为“1 原币 = X 人民币”。

USDT 使用 [Kraken 公共行情接口](https://docs.kraken.com/api-reference/market-data/get-ticker-information)的 USDT/USD 最新成交价，再乘以美元兑人民币参考汇率。它是合成参考值，使用两个来源的时间信息，不将 USDT 强制当成 1 USD。

联网仅查询固定的公开币种行情，不发送账户名称、余额、尾号、账单或订阅数据，不连接银行或发起支付。本机请求固定通过现有 HTTP 代理 127.0.0.1:10090 建立经过 TLS 验证的通道；代理失败时停止请求，不回退直连。程序不修改系统代理。

汇率缓存单独保存在账本数据目录的 exchange-rates.json，账本仍保存在本机。应用首次成功取得行情前不编造汇率。

## 原币、估值与历史

- 账户余额按原币保存，资产汇总按账户当前汇率折成人民币。自动更新只调整估值汇率，不改变原币余额。
- 收入、支出保存当笔汇率快照，之后汇率变化不会改写历史。订阅自动记账使用处理时可用的账户汇率；离线补记不查询每个历史日期的行情。
- 跨币种转移分别填写转出和实际到账金额，不自动兑换、不计为收支。
- 预算、储蓄目标和综合统计仍使用人民币。

| 币种 | 支持的小数位 |
| --- | ---: |
| CNY、USD、EUR、HKD、GBP、SGD、AUD、CAD、CHF、TRY | 2 |
| JPY、KRW | 0 |
| USDT | 6 |

汇率最多保留 8 位小数，人民币估值按分舍入。已有账单或订阅的账户固定币种，其他币种应另建账户。

## 备份与兼容

JSON 备份包含原币金额、账户汇率模式和历史汇率快照。多币种账本使用 schemaVersion 2，请使用支持多币种的新版恢复。汇率缓存可重新获取；自动模式恢复时会使用本机已有或之后取得的最新报价。
