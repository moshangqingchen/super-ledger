# Windows 1.8.0 界面与更新验证

本次更新为 Windows 视觉与更新交互改进；Android 继续使用原签名的 1.2.0（10200）安装包。金额计算、数据结构和同步协议未变更。

- Node 自动测试 135 项通过，包括更新控制器 11 项与说明提取/格式化 4 项；既有签名、安装包校验、取消、代理无直连与账本保护检查保持通过。
- 隔离 Electron 检查七个页面在 1360 / 960 像素宽度下均无横向溢出或图片缺失、无渲染错误；验证隐私模式、账单/转账/账户/订阅表单、手机扫码入口和空账本。
- 更新窗口验证自动提示、转义与折叠说明、42% 下载进度、后台下载、取消、安装双阶段确认、安装失败重试、键盘焦点、表单打开期间延后显示、手动检查最新版本、960×680 最小窗口。
- 所有交互测试使用隔离的演示或空账本，无真实安装、支付或外网请求。

## 发布边界

更新仍使用既有 RSA 签名公钥、安装包长度及 SHA-256 校验，通过本机固定代理获取。安装必须由用户确认，主进程再次检查未关闭的编辑表单。原生文件选择和系统错误提示继续使用系统界面。

桌面安装包未配置 Windows Authenticode 证书；更新清单签名不等同于系统发布者签名。此轮未重新测试安卓真机，未声称通过 vivo 真机验证。
