# Android 1.3.1 下载修复

用户手机 1.1.0 在下载 1.3.0 时停留在 0%。旧实现的取消只设置标志，10 分钟期限只在读取返回后检查，不能保证 DNS、响应头或首包等待时及时退出；一个请求阻塞还会占住更新工作线程。截图不能确认手机究竟在哪个连接阶段受阻，显示候选版本也可能来自本地缓存。

## 修复范围

- 连接、响应头和读取由独立传输任务处理，协调线程对整段操作设限；无真实数据进展 45 秒或整体 3 分钟会结束等待。系统连接/读取超时仍保留。
- 每次请求使用独立取消对象和唯一临时文件；超时或取消后，旧任务不能更新新请求的进度、安装就绪状态或文件。传输线程及断开连接线程有数量上限，不因连续重试无限创建线程。
- 连接阶段显示等待状态；实际接收数据后才显示百分比。增加浏览器下载入口，仍使用经签名验证的原 GitHub 地址。
- 保留原 HTTPS 来源与跳转白名单、文件长度、SHA-256、包名、版本及 APK 签名校验；未修改账本格式、识别、同步和授权开关。

## 旧版本如何升级

修复只有安装 1.3.1 后才生效。旧版若已卡住，可通过手机浏览器下载官方安装包；手机网络无法访问 GitHub 时，把电脑下载的原签名 APK 传到手机直接覆盖安装一次，**无需卸载旧应用**。浏览器使用同一来源，不保证能解决网络访问问题。

## 验证边界

- 76 项新增模拟 HTTPS 检查通过，Java 检查总计 327 项通过；包括 DNS/响应头/读取/断开连接不响应中断，取消及时返回、输入流迟到、缓存清理、重试隔离、线程池容量恢复及持续小流量的总限时。
- 1.3.1 / 10301 APK 离线编译、原证书 v2/v3 签名、16 KiB ZIP 对齐及包名/SDK 检查通过；没有新增权限。APK 为 1,574,944 字节，SHA-256 为 `1afa7021b58cff5f513e90e06f1a15510984235981bf08113b7a60579ab813b1`。
- 生产 Android 更新策略验证候选清单及真实 APK，从用户截图中的 10100 提供 10301，并验证同版本抑制、签名篡改拒绝。Windows 安装包和清单字段仍保持 1.8.0 原样。
- 包内生成图片与原图字节一致，更新公钥不变，没有个人账本、源代码或签名私钥。

传输故障测试使用可控制的 HTTPS 连接替身，覆盖阻塞、超时、取消与迟到结果，不访问外网。公开发布验证只通过电脑指定代理进行，不能证明用户手机到 GitHub 的网络正常。没有运行 Android 模拟器，也没有在 vivo X200 Ultra 实测系统浏览器、安装器或真实 DNS 行为。
