# Android 1.3.2 免费更新线路

手机现在可自动切换两个免费中转入口及 GitHub 正式来源，版本清单与 APK 下载都参与切换。设置也可以指定单一线路。使用中转时，仍只请求本仓库的公开签名清单及正式安装包，不携带 GitHub 登录凭据，不读取或上传账本。

## 线路与使用范围

- GH-Proxy：`https://gh-proxy.org/`，按其[使用文档](https://gh-proxy.com/docs/github-accelerator)代理 GitHub 公开 Raw 与 Releases 文件。
- GHFast：`https://ghfast.top/`，对应[服务入口](https://ghfast.top/)。
- GitHub：保留原 `raw.githubusercontent.com` 签名清单和 `github.com` 正式发布 URL。

这不是新购的国内 CDN，也没有开通付费托管服务。免费第三方可用性可能变化；电脑通过现有代理能下载，不等于用户手机或所有国内运营商都能下载。用户可以在手机上选择线路检验实际体验。

初始筛选时，前两条线路对 1.3.1 清单与 APK 均返回 HTTP 200，完整字节和已发布文件 SHA-256 一致；通过本机指定代理观察到约 0.7–2.2 秒完成。另一个候选线路 APK 耗时约 102 秒，未纳入应用。该计时仅用于本次筛选，不是手机速度承诺。

## 兼容与安全

签名清单保留旧版认可的 `android.url`，新增 `android.sources` 并随每次发布重建相同 APK 的三条地址，防止继承旧版链接。每个地址严格限制到固定服务及本仓库对应文件；清单不跟随重定向，APK 跳转逐跳验证。发布签名、APK 长度、SHA-256、包名、版本及原证书检查均保留。

单次更新的取消与总期限跨线路共享，单条线路无数据进展会让出机会；每条尝试拥有独立临时文件，迟到请求不能干扰重试。网络错误可换线，错误签名、文件哈希或应用身份不能以换线为理由放宽。已验证最高版本及文件身份持久化，较旧镜像不会清空已发现的新版本，同版本换包会被拒绝。

## 首次升级

1.1–1.3.1 只内置 GitHub 入口，无法通过修改服务端清单远程添加新代码。用户可以在手机浏览器打开本次发布的备用 APK 直链，按系统提示覆盖安装一次，无需卸载。安装 1.3.2 后，即可在手机应用内使用多线路检查和升级。
