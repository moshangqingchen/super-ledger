# 手机记账与扫码同步

电脑版 1.8.8 · 安卓版 1.3.5（Android 8.0 及以上）。首个适配目标为 vivo X200 Ultra，实际通知样式、付款页面与后台策略仍需在你的手机上验证。新版手机完整账本同步需要电脑 1.7.0 及以上。

## 第一次使用

1. 从 [GitHub Releases](https://github.com/moshangqingchen/super-ledger/releases/latest) 下载 Windows 安装包 `SuperLedger-Setup-1.8.8.exe`。覆盖安装会继续使用本地账本。
2. 从同一发布页下载 `SuperLedger-Mobile-1.3.5.apk`，传到手机并安装。Windows 安装包也内附该 APK。
3. 让手机和电脑处于同一 Wi-Fi/局域网，或让电脑连接手机热点。电脑可以使用同一路由器下的网线连接。
4. 电脑打开「手机同步」，手机打开「同步」→「扫一扫，开始同步」。首次会把电脑账本带入手机；手机已独立创建的账户和记录会合并，不按账户名称猜测对应关系。二维码十分钟有效，关闭同步面板即停止连接；使用手机 App 扫码，普通相机不能代替 App 同步。
5. 在手机「设置」开启自动采集，并手动授予「通知使用权」。选择需要的支付/银行应用；为通知不含银行卡尾号的来源设置默认记账账户。微信支付也可能走银行卡，不会擅自当作微信零钱。
6. 按手机系统实际设置允许后台运行。vivo 的后台/自启动选项名称随系统版本变化；若从安装包安装的应用被系统限制敏感设置，按系统提示手动允许。授权随时可在系统设置撤销。

## 日常使用

电脑 1.6.0 / 手机 1.1.0 起会检查 GitHub 发布的对应平台更新，有新版本时提供「下载更新/稍后」选择。你选择下载并通过校验后，仍需确认安装。Windows 覆盖原安装；安卓会要求允许本应用安装并显示系统安装确认，同包同签名更新保留账本。旧版本尚未包含更新器，需要先手动装本次新版一次。更新期间不要卸载应用。

外出期间，手机保存已识别的通知和手动账单，不需要电脑在线。回来后连接同一网络，再扫一次电脑二维码即可。手机/电脑的账户、收支、转账、订阅、预算与储蓄心愿修改会逐项核对，双端同时改动的内容留在手机「待确认」中处理。删除也会同步，已确认的重试不会再次扣账。

通知缺少账户、退款/还款/转账、含多个金额、疑似重复的交易先进入待确认。微信/银行可能通知同一笔扣款，系统不会仅凭相同金额悄悄删除其中一笔。订阅计划已记过的费用会提示核对，避免多扣一次。

手机版可查看总资产、今日/月度收支、分类支出与预算，管理账户、收入支出、账户转账、订阅计划和储蓄心愿。支持与电脑相同的 13 种币种，按整数最小单位计算；总资产按账户当前汇率折合人民币，历史收支保留入账时汇率。手机使用同步取得或手动填写的汇率，公开汇率自动刷新仍在电脑端完成。

到计划扣账日会自动记账、漏记账期会补记；两端同一账期只保留一笔。金额或账户不同会要求核对。删除订阅保留历史支出；删除已记账的订阅支出不会让该账期重新补记。自动扣账只影响账本，不向支付平台发起扣款。

账单支持月份、账户、收支类型、分类及文字筛选和 CSV 导出。手机可导出/恢复包含离线队列的完整 JSON 备份，恢复前保留当前内容。首次同步前也可独立创建账户和记账。

## 微信、支付宝扫码买菜

通知明确显示付款成功、实际金额与可确定的资金账户时，可自动入账；实付金额优先于原价、优惠、手续费和余额。银行卡资金来源优先于微信/支付宝的默认钱包映射，多张卡尾号冲突或金额不明确时进入待确认，不猜测扣款账户。

只有付款页有结果、没有通知时，可在手机设置开启「付款页辅助识别」，再亲自在系统辅助功能设置授权。此功能默认关闭，随时可关闭；它还受自动采集总开关和来源开关控制。仅识别微信/支付宝允许的付款窗口中明确成功的结构化结果，不截图、不点击、不填写、不操作支付，不记录聊天或输入内容。付款页结果先进入待确认，核对实付金额、商家和账户后入账；没有支持的页面结构时不识别。通知与付款页的同订单、疑似重复项共同核对。

## 连接不上时

- 确认两端连接同一网络，二维码尚未过期，电脑同步窗口仍打开。访客 Wi-Fi 可能隔离设备，换用手机热点通常更容易排查。
- 多网卡电脑在同步窗口选择手机所在的网卡地址。只支持私有 IPv4 地址，不使用公网穿透。
- Windows 防火墙阻止连接时，点击连接帮助中的「允许局域网连接」，在 Windows 系统弹窗授予管理员权限。此动作仅添加当前超级账本程序的 **LocalSubnet 入站 TCP 规则**，只绑定私有本机地址；不关闭防火墙，不更改网络类别或代理。
- 若取消 Windows 授权，账本仍可正常使用，局域网连接可能继续被防火墙阻止。高级用户也可用管理员 PowerShell 运行随附 `enable-mobile-sync.ps1`；`-Remove` 只移除本工具为该程序创建的规则。
- 安卓相机未授权时可粘贴电脑提供的临时配对内容。配对内容含本次同步密钥，请勿分享给别人。

## 数据与权限

账本保存在两台设备。同步使用二维码携带的随机密钥进行 AES-256-GCM 认证加密，局域网传输的是密文；电脑仅在同步窗口打开时启用独立临时接口，不对局域网开放原本的桌面账本接口。不同设备/每次新二维码使用独立会话；不上传账本到云端。

相机只用于扫描配对码，照片不上传。通知采集默认关闭，需手动启用；按所选来源过滤，仅识别金融通知，验证码不会用于记账。待确认可能保留一小段金融通知供核对。短信识别可通过你明确添加的短信应用金融通知实现，本版不直接读取短信数据库，不请求通讯录、定位、录音或 Root。可选辅助功能服务需另外手动授权；只保存付款字段，不保存整页文字。

安卓应用私有目录保存账本，系统云备份关闭；可从手机设置导出本地备份。换手机或卸载前务必导出/同步，卸载会删除该手机的本地数据。电脑版仍保存在 `%APPDATA%\SuperLedger\data\ledger.json`，每次保存保留上一份备份。

电脑恢复/重置账本后配对身份会变化，防止旧手机离线修改错误地写入新账本；请先在手机导出备份，再按手机提示重新配对并逐项处理旧待同步记录。

现有电脑账本保存上限为 2 MB（含持久化去重记录），手机本地保存上限为 16 MB。达到上限会停止保存并显示错误，不自动丢弃历史；应先导出备份处理容量问题。

自动采集依赖可读取的交易通知或已启用且支持的付款结果页。聊天内消息、未显示金额、系统隐藏内容、现金交易及手机强制停止/后台限制期间无法保证捕获。未做 vivo 真机验证前，不把覆盖率视为百分之百；建议首次用几笔日常小额交易核对。

## 开发记录

- 原生 Java，minSdk 26 / targetSdk 35，ZXing 3.5.3；本地签名 APK，可安装更新。签名材料只在开发目录 `android/.signing` 保存，不打包到安装包，后续升级需保留它。
- `powershell -NoProfile -ExecutionPolicy Bypass -File android/build.ps1` 离线生成 APK。
- `node desktop/build.cjs` 离线生成完整 Windows 安装包（需已生成 APK）。
- `npm test` 运行账本与同步回归测试；构建依赖下载脚本只经既有 `http://127.0.0.1:10090` 代理，不回退外网直连。
- 协议及测试依据：Android NotificationListenerService、Android 应用沙箱、Android 后台限制、Node.js crypto 官方文档。SDK 与第三方库来源/许可证在 `android/tools/README.md` 和依赖记录中。

电脑 1.8.5 和 Android 1.3.4 均可新增及编辑 Apple 账户／礼品卡余额，选择美国、日本、土耳其等地区与对应币种，并填写关联 Apple 账号。手机入口为「资产 → 添加账户 → 选择 Apple 余额」，外币汇率可手动填写；已有自动汇率仍从电脑同步。旧 Android 1.3.2 不识别 TRY，请先覆盖升级。

两端订阅均支持 Suno、Grok，卡片及编辑表单显示扣款账户的当前账本余额、本次费用及不足差额；关联邮箱、Apple 等登录账号另行标注。到期日期仅用于颜色提醒，不改变自动记账规则。手机每次打开自动检查更新，发现新版后可选择下载和安装；查看普通页面、旋转和返回权限界面不会重复检查。
