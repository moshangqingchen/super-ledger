# Windows 1.8.17 / Android 1.3.13

- 电脑版新增每日支出、近半年收支对比、预算节奏和分类下钻，支持跨月搜索与筛选导出。
- 电脑版记账支持账户和分类快捷选择、历史标题建议、今天／昨天、保存后继续记账；账单、订阅和心愿删除后可在 6 秒内撤销。
- 两端订阅支持月、季、半年和年付，按实际账期记账并顺延期限，保留历史已处理账期。
- 两端新增分类预算、自定义分类、心愿目标日期和储蓄建议；手机可直接为历史账单中的自由分类设置预算。
- 修复离线周期修改覆盖电脑同期续期的问题；遇到这种并发修改会保留电脑记录，并提示采用最新记录后重新编辑周期。
- 修复删除同名收入自定义分类时误删支出预算的问题。
- 新周期、分类预算、自定义分类和目标日期使用 schema 4，请电脑与手机一起升级；未使用新字段的旧账本保持原结构。
- Windows 安装包内附 Android 1.3.13 APK。
