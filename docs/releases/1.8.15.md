# Windows 1.8.15 / Android 1.3.11

- 新增「订阅星图」，以 7 / 15 / 30 天同心轨道展示到期远近，沿用现有浅紫、柔光和圆角卡片。
- 电脑版增加「图表」展示方式，手机版增加星图与列表切换，并记住视图选择。
- 集中显示待扣账、已到期和单笔余额不足情况，会员期限与北京时间扣账时间分别显示。
- 「续费准备」按扣款账户合并全部启用订阅的各下一笔费用，使用账户原币核对余额和缺口；共享账户的余额只计算一次。
- Windows 安装包内附 Android 1.3.11 APK。
