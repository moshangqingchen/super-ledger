# Windows 1.8.18 / Android 1.3.14

- 修复工行消费短信识别：支持「交易金额／账号／交易内容」字段，以及「尾号…支出(消费…)金额元」形式的原文。
- 兼容已知银行服务号码和精确银行显示名；支持 0.01 元、换行字段，并排除账户余额。
- 依据银行及四位尾号匹配实际扣款卡，覆盖不符的来源默认账户；缺卡、多卡、冲突信息和多笔合并通知进入待确认。
- 加强完整或分组卡号、重复交易字段及未完成交易的判断，保留验证码、失败及预告交易过滤和重复通知防重。
- Windows 同步发布 1.8.18，内附与本次正式上传完全一致的 Android 1.3.14 APK 和更新后的短信使用说明，继续使用现有同步协议与账本结构。

升级后请在手机设置中打开自动记账总开关与通知访问，并通过「添加其他银行 / 短信应用」启用实际短信应用，在工行账户填写正确的四位尾号。已错过的短信不会自动回溯补记。实际通知与后台行为仍需在手机上验证。
