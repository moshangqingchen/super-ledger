# 超级账本 · Windows 1.8.6

- 账户选择更直观：订阅扣款、收支记账、转账和账单筛选都显示银行或平台 Logo，同时展示账户名称、尾号、地区和币种。账户较多时可以搜索，转账选择仍显示余额。
- 表单更好辨认：会员服务、档位、分类、币种和关联账号配上图标；日期、金额及信息分区增加小图案。补齐 Apple、Google、QQ 官方标识，自定义账户使用类别图标。
- 改善选择体验：支持键盘操作和中文搜索，下拉列表适应窗口空间；窄屏订阅表单改为单列。升级保留原账本。

Windows 下载 `SuperLedger-Setup-1.8.6.exe`，或在旧版应用「账本设置 → 检查更新」中下载覆盖安装。

Android 继续使用已发布的 `SuperLedger-Mobile-1.3.4.apk`，本次未新增手机版本。此页提供同一份原始 APK，电脑安装包中也内附该版本。

本版通过核心回归、隔离桌面界面检查和安装包启动验证；检查了账户切换、跨币种费用、转账目标、保存结果及 1440／960／390 像素布局。
