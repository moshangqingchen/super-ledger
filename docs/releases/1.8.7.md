# Windows 1.8.7 与 Android 1.3.5

Windows 的财务总览、收支账单、账户、订阅、分析、心愿和设置统一了卡片光影、字阶与操作状态。窄屏账单把金额和日期放在每笔记录内，订阅费用、到期提醒与扣款余额分区显示。

自动补记订阅遇到金额上限时，仍可打开和导出最后一份有效账本。界面会显示错误并提供进入订阅管理的入口。另修复了中文组词时账单搜索被打断、隐藏金额后日历悬浮提示仍显示价格、外币小额支出折算为零时分类占比异常，以及长订阅名称撑宽总览的问题。

Android 1.3.5 调整了原生卡片、底部导航、表单和订阅金额层级。Windows 安装包内附 Android 1.3.5，也可单独下载 APK。

账户页采用原生界面绘制的卡片：各银行和软件使用不同的浅品牌色，配合柔和材质光影、薄高光边和局部装饰，形成清晰的层次。Logo 放在角落，名称、主要余额、尾号及汇率依次排列，账单操作位于底部，金额保持醒目。

- 默认按银行合并。同一银行使用全宽摘要展示人民币折算总额、卡片数量和各原币小计；负余额计入合计。
- 点击「展开」后，在摘要下方按网格展示该银行的独立卡片。每张卡显示本币余额、尾号及人民币估值，并保留编辑和账单入口。
- 每家银行可直接「添加银行卡」，自动选择所属银行；保存后展开该银行，显示新增卡片。
- 「全部单卡」可切回独立账户视图。钱包、Apple 余额、现金、自定义和未选择银行的账户继续独立展示。
- 合并仅改变展示方式，不修改账户 ID、账单、订阅、转账或同步数据结构。
