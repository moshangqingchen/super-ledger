# Windows 1.8.9

- 账户卡片更有质感：四边有柔和的光，每类账户都有相关的小元素。同一家银行有多张卡时，合并后能看出是一叠卡，展开时卡片依次出现；还可以一键全部展开或收起。负余额显示为红色。
- 订阅卡片按服务换上各自的颜色和可爱的小元素，比如 Claude 的小螃蟹、网易云的黑胶唱片、B 站的小电视。
- 订阅页新增「详细／简约」切换。简约版只留价格、到期和余额是否够扣等关键信息，一屏能看到更多订阅，应用会记住你的选择。
- 同一行订阅卡片的扣款面板、登录账号和日期上下对齐，比较起来更方便。
- 修复：编辑某条记录时，如果它已在别处被删除（比如手机同步），保存会提示「已保存」但修改丢失。现在会明确提示，并保留已填写的内容。
