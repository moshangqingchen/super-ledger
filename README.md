# 超级账本 · Windows + Android

独立窗口、本地保存的 Windows 应用，无需浏览器或额外安装 Node.js。

[下载电脑与安卓安装包](https://github.com/moshangqingchen/super-ledger/releases/latest) · [手机扫码同步](docs/mobile-sync-guide.md) · [版本发布与更新维护](docs/releasing.md)

## 安装与打开

从 GitHub Releases 下载并运行 `SuperLedger-Setup-1.8.0.exe`（本机构建名称为 `release/超级账本-安装-1.8.0.exe`），安装到当前用户并创建桌面、开始菜单快捷方式。也可直接打开 `release/win-unpacked/超级账本.exe`；未安装版必须保留整个 win-unpacked 文件夹。根目录的 `启动账本.cmd` 会打开桌面应用。

安卓版安装包为 `SuperLedger-Mobile-1.2.0.apk`，也随电脑版安装包附带，可从「手机同步」→「获取安卓安装包」打开。新版手机需电脑 1.7.0 及以上。可先在手机独立建账，再在同一 Wi-Fi/手机热点下扫码合并；外出离线记录，回来扫码同步。详见 [手机记账与扫码同步](docs/mobile-sync-guide.md)。

电脑 1.6.0 / 安卓 1.1.0 起支持可选择的覆盖更新：打开应用会定期检查对应平台的新版本，设置里也可手动检查。新版本需你确认才下载，校验发布签名与安装包 SHA-256 后再确认安装，保留原账本。之前不带更新功能的版本，需要先手动安装一次新版。关闭的应用不会自行运行或弹出更新。

关闭窗口默认收起到系统托盘，后台继续处理到期订阅。双击托盘图标或桌面快捷方式恢复窗口；托盘菜单或设置里的「退出应用」可完全退出。在设置里关闭「关闭窗口后留在托盘」后，窗口 × 会直接退出。不会设置开机自启动。

首次打开默认是空账本：账户、收支、订阅、储蓄心愿均为空，预算未设置，所有金额为零。点击「添加账户」后填写自己的余额开始使用。会员服务与 Logo 是可选目录，不会自动创建订阅记录。

## 功能

- Windows 1.8.0 使用应用内更新窗口：三条重点与折叠说明、下载进度、后台下载、取消和重试；安装前单独确认，填写账单时自动提示会等待。

- 清爽浅色与蓝紫桌面界面：柔和留白、统一侧栏与卡片，AI 生成的钱包装饰，突出净资产、今日支出和快捷记账入口，最近账单与订阅次之，预算心愿更轻。空账本从添加第一个账户开始，数据全部由你填写。

- 微信、支付宝、银行卡、现金、虚拟卡账户快捷选项与对应标识，选好后手动填写余额，可改账户名称。不会自动创建账户或预填资金。
- 银行卡可选工商、建设、农业、招商、中国、交通、邮储、平安银行及官方 Logo，可自填昵称和四位尾号；同一家银行可添加多张卡，选择账户时展示银行、昵称和尾号。
- 转移资产：在现有账户中选择转出、转入账户；显示两边当前余额，更新余额但不计入收入或支出。
- 多币种收入、支出、账户余额和总资产，按各币种整数最小单位计算；CNY 默认，支持 USD、USDT、JPY 等。
- 每日自动查询公开汇率，也可手动刷新或为单个账户设手动汇率。断网沿用缓存，历史收支汇率保留。详见 [汇率与币种说明](docs/currency-behavior.md)。
- 每日收支、月度账单筛选、CSV 导出、预算与分类统计、储蓄心愿。
- ChatGPT、Claude、Gemini、TT语音、酷狗音乐、百度网盘等9个会员预设，包含官方Logo和已核实档位。档位可下拉选择或自填，金额按实际支付价格填写。
- 连续订阅按日期每月自动记账；单次订阅只记一次。月末适配短月份，漏记月份下次启动补记，同一账期不重复；暂停期间账期恢复后不补扣。
- JSON完整备份导入/导出；原生文件对话框；导入前自动保留独立备份。
- 安卓总资产与账户余额、今日/月度收支、分类与预算、12 种币种收支及转账、账户和订阅管理、储蓄心愿、筛选/CSV 导出、完整手机备份恢复；所有账本实体支持局域网加密同步、离线重试去重和双端修改冲突处理。
- 微信/支付宝扫码消费通知优先识别实付金额与实际资金账户，银行卡绑卡扣款不会默认计入零钱。金额、账户或重复关系不明确时待确认。可选付款页辅助识别默认关闭，由你手动开启并授予系统辅助功能权限，仅识别明确付款结果、无点击或支付操作，页面结果先待确认；没有可读取通知或支持的页面时无法保证捕获。

自动扣账只影响账本余额，不会向银行卡或平台发起实际支付，也不会取消平台会员。当前周期为月度或单次，不要把年费设置为每月自动记账。

## 本地数据与迁移

桌面数据位于 `%APPDATA%\SuperLedger\data\ledger.json`，与程序分开保存，安装更新或卸载默认不删除它。设置中可以直接打开数据文件夹。

首次打开会在旧版已退出后验证本项目 data/ledger.json，先保存独立备份，再迁移到新目录；原文件保持不变。目标已有账本时绝不覆盖，旧文件损坏或进程状态无法确认时停止迁移。迁移后请统一使用桌面版。

每次保存保留 ledger.previous.json，导入/重置另有时间戳备份。导出不能覆盖内部账本/配置或迁移源。数据为本机明文文件，无云同步，建议定期导出。损坏恢复：完全退出应用，另存损坏文件，再用 previous 或导出备份复制为 ledger.json，重新打开。

## 会员与图标来源

档位为核对当日的静态候选，地区或版本变化可自填；预设不包含实时价格。详见 [会员来源](docs/subscription-sources.md)、[官方图标来源](docs/brand-assets.md)、[银行 Logo 来源](docs/bank-logo-sources.md)。会员Logo为官方原文件；应用图标为代码原生的书本标记。

## 开发与构建

- `npm test`：核心金额、订阅、会员、迁移、导出保护、本地服务测试。
- `npm start`：启动桌面应用。
- `node desktop/build.cjs --check`：离线预检。
- `node desktop/build.cjs --dir`：生成未安装目录。
- `node desktop/build.cjs` 或 `build.ps1`：生成Windows x64安装包。
- `npm run start:web`：仅供开发的旧网页预览。

使用本机已有Electron43.3.0 / electron-builder26.15.3，LEDGER_DESKTOP_TOOLROOT可指定已有node_modules工具目录。工具缺失停止，不自动下载。安装包为本地构建，未配置发布者代码签名。

默认构建工具目录为项目 `node_modules`，可通过 `LEDGER_DESKTOP_TOOLROOT` 指向已有依赖。应用图标已随源码提供；重新编译图标需安装 `sharp` 或指定 `LEDGER_SHARP_PATH`。构建安卓需要的 SDK/ZXing 下载与离线构建说明见 [Android 工具说明](android/tools/README.md)。个人账本、构建输出、SDK、更新签名私钥与安卓签名材料均不进入 Git 仓库；安装包单独发布在 Releases。

桌面内部服务使用随机回环端口和每次启动新建的会话凭据；渲染隔离、禁止Node集成、仅加载本地资源。打开手机同步面板时，另外在选定私有 IPv4 网卡启用临时加密接口，十分钟到期或关闭面板后停止；不向局域网开放内部账本 API。只同步账本，不上传云端。

后台公共汇率查询仍全部通过现有127.0.0.1:10090代理并验证TLS，失败不回退直连。局域网同步无需互联网，不改动全局代理或网络类别。防火墙辅助按钮仅在用户点击并通过 Windows 管理员授权后，添加当前程序的本地子网入站规则。实现参考 [Electron官方安全指南](https://www.electronjs.org/docs/latest/tutorial/security)。

Windows 更新检查和下载同样只经该代理，失败不直连。安卓更新走手机当前 HTTPS 网络/系统代理设置，仅访问公开版本清单和安装包；账本仍只在你扫码连接的局域网设备间同步。更新清单使用独立 RSA 签名，两端内置同一公钥；安卓安装前还核对包名、版本和签名证书，由系统要求你确认安装。
